# Agent Skills Repository

A collection of specialized AI agent skills for use with various agentic runtimes. Each skill is a self-contained directory providing specific domain expertise or functional capabilities.

## Core Workflow
- **Installation**: Skills are restored to your agent's skill directory. See the `restore_skills.py` script for supported clients (e.g., `pi`, `claude`, `gemini`).
- **Structure**: Each skill directory must contain a `SKILL.md` at its root. 
- **Maintenance**: Use `update_readme.py` for documentation and `restore_skills.py` for environment syncing.

## High-Signal Facts
- **Flattening**: Ensure no nested `skills/` directories exist. All skills must reside directly under the agent's skill directory.
- **Self-Containment**: Skills should be self-contained. Avoid external references unless explicitly created during the skill's execution.

## Commands
- **Restore Skills**: `python restore_skills.py . --client [gemini|pi|claude|opencode]`
- **Sync Skills**: `python sync.py [deploy|save] --client [gemini|pi|claude]`
- **Update Docs**: `python update_readme.py`

## Security & Integrity Guardrails
- **Path Containment**: All sync and restore scripts enforce strict canonical path containment (`is_safe_subpath`) and alphanumeric directory validation.
- **Symlink Protection**: Automated tools disable symlink traversal to prevent unauthorized filesystem access.
- **Secret Hygiene**: Ensure no private keys, `.env` configs, API credentials, or database files are committed. Refer to `.gitignore` and [ADR-0006](adr/0006-repository-security-posture-hardening.md).

## Testing & Verification
- Verify skill installation by checking the target client's skills directory (e.g. `~/.gemini/config/skills` or `~/.pi/agent/skills`).
- Use `skill-judge` to audit the quality of new skill definitions.
- Compile and run syntax/security checks with `python -m py_compile *.py`.
